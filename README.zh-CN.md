## YTKTV Desk：管理多个包厢的管理终端

<p align="center">
  <img src="docs/images/desk.png" alt="YTKTV Desk：房间格子墙显示每个房间的状态、客人、剩余时间、消费和正在唱的歌，右边是订单，下面是服务呼叫" width="860">
</p>

家里不止一个房间？在一台电脑上运行 **YTKTV Desk**，把每台 YTKTV 绑定上去，就像真 KTV 的管理终端管包厢一样：大人一间、小孩一间。

- **开房、续时、关房**：1～3 小时或不限时。关着的房间显示「This room is closed」，电视全黑；时间到了等这首歌唱完再关房。
- **呼叫和点单**：客人在控制台或手机上呼叫服务、从菜单点东西，管理终端会「哔」一声，房间格子闪烁。
- **收银**：按小时（可以每间房不同价）、最低消费、打折、抹零，现金、刷卡、微信、支付宝或会员余额付款；账单可以打印或存 PDF，也能用任何已安装的打印机打 58/80mm 小票。
- **会员**：储值、积分、会员价。
- **日常管理**：预定（日历和时间轴）、房型和座位数、待清洁和维修、换房、全场广播、远程切歌暂停调音量、交班报表、每日记录。
- **安全**：用一次性配对码和四个图案的安全码绑定；房间只听管理终端签了名的指令；管理终端换了 IP 也能按 ID 找到；绑定是永久的，除非管理终端连续 7 天不在线；管理终端可以设密码。

从[最新 Release](https://github.com/TonyD365/YTKTV/releases/latest) 下载 `YTKTV-Desk-<版本>-…`，然后在每个房间的 YTKTV 里打开 **Settings → Staff Terminal**，点 **Find Desks**，输入管理终端上显示的配对码。详细步骤见 [管理终端使用指南（英文）](docs/guide/front-desk.md)。

## 快速开始

1. 从[最新版本](https://github.com/TonyD365/YTKTV/releases/latest)下载对应系统的安装包并安装（macOS 需要先执行一条 `xattr` 命令，见下面的[安装](#安装)）。
2. 把电视作为第二块屏幕接上，**尽量用 HDMI 线**（原因见[常见问题](#常见问题)），然后打开 YTKTV。第一次启动会有一个简短的向导，选音箱、选屏幕、试麦克风。
3. 用手机扫屏幕上的二维码，点首歌，开唱。

如果 YTKTV 让你们的聚会更开心，在 GitHub 上点个 ⭐ 能帮更多人找到它。

## 安装

| 系统 | 文件 |
|---|---|
| macOS（Apple 芯片和 Intel） | `YTKTV-<版本>-macos-universal.pkg` |
| Windows 10/11（64 位） | `YTKTV-<版本>-windows-x64-setup.exe` |
| Linux（x86-64） | `YTKTV-<版本>-linux-x86_64.AppImage` |
| Windows ARM 电脑 | `YTKTV-<版本>-windows-arm64-setup.exe` |
| Linux ARM（64 位，比如树莓派 4/5） | `YTKTV-<版本>-linux-aarch64.AppImage` |
| 管理终端 YTKTV Desk，macOS（Apple 芯片和 Intel） | `YTKTV-Desk-<版本>-macos-universal.pkg` |
| 管理终端 YTKTV Desk，Windows | `YTKTV-Desk-<版本>-windows-x64-setup.exe` |
| 管理终端 YTKTV Desk，Linux | `YTKTV-Desk-<版本>-linux-x86_64.AppImage` |
| 管理终端 YTKTV Desk，ARM | `YTKTV-Desk-<版本>-windows-arm64-setup.exe` 或 `-linux-aarch64.AppImage` |

安装包还没有付费签名。**macOS** 上打开安装包前，先在"终端"里去掉下载隔离标记：

```bash
xattr -d com.apple.quarantine ~/Downloads/YTKTV-<版本>-macos-universal.pkg
```

装好后如果仍提示"已损坏"或"无法打开"，再执行 `sudo xattr -dr com.apple.quarantine /Applications/YTKTV.app`。**Windows** 上如果 SmartScreen 拦截，点"更多信息 → 仍要运行"。

**YTKTV 会提示安装 mpv。** YTKTV 用 [mpv](https://mpv.io) 播放视频，它是另一个以 GPL 发布的免费软件，不属于 YTKTV，也不在 Release 里。启动时如果找不到 mpv，程序会提示用你系统惯用的方式安装：macOS 用 [Homebrew](https://brew.sh) 执行 `brew install mpv`（没有 Homebrew 会告诉你怎么装，装好后点"Check Again"）；Windows 从 [mpv.io](https://mpv.io/installation/) 列出的 Windows 版下载；Linux 用系统的包管理器安装（会要求输入密码）。已经下载过 mpv 的 1.4、1.5 版用户不受影响。

人声分离：Apple 芯片的 Mac 内置，用 GPU；Windows 和 Linux 第一次运行时按显卡自动下载（NVIDIA、Windows 上的其他 DirectX 12 显卡，或者纯 CPU）；Linux ARM（比如树莓派）第一次运行时下载 CPU 版，树莓派上一首歌要几分钟；Windows ARM 电脑第一次运行时下载 CPU 版，通过 Windows 自带的 x64 模拟运行；Intel Mac 暂不支持 AI 分离，但"消人声"和左右声道模式可用。

## 功能

- **点歌**：搜索有联想和历史记录，**拼音首字母点歌**（输入 `yldb` 找到《月亮代表我的心》），歌手页按语种（国语、粤语、英文、日语、韩语）和男歌手、女歌手、组合分类，热门榜，YouTube 链接直接点，歌单和导入 YouTube 播放列表。
- **原唱 / 伴奏**：AI 分离，两条音轨同时播放，切换无缝；导唱滑块可以保留一部分原唱。分离好的伴奏会缓存，同一首歌下次不用再等。
- **歌词**：用视频的字幕，没有就用 YouTube 自动字幕，再没有就去 [LRCLIB](https://lrclib.net) 找带时间的歌词；颜色逐字跟随演唱，歌词偏早偏晚可以按 0.1 秒微调，按歌记住。
- **打分**：边唱边显示音高线，金色表示唱准了；唱完显示分数和本场排行榜，对唱时每支麦克风单独打分。不同八度唱也算对。
- **调音台**：四路麦克风，增益、三段 EQ、压缩、回声、混响、声像、推子、静音；效果预设（流行、抒情、摇滚、KTV 大厅、干声，以及自己保存的）；防啸叫分关、低、中、高四档。
- **手机**：扫码点歌、遥控、调麦克风；每部手机能看到自己点的歌还要等多久；手机还能直接当麦克风用。
- **氛围**：弹幕（电脑和手机都能发）、鼓掌欢呼等音效按钮、随音乐变化的氛围灯。
- **小游戏**：12 个游戏，控制台和手机上每个都有自己的界面：骰子、谁唱下一首、真心话大冒险、数字炸弹、大话骰（各自在手机上看自己的骰子）、随机点歌、唱歌挑战卡、抽签、比大小、逢七过、倒计时、抛硬币。
- **离线下载**：歌曲上点 ⬇（或者「下载全部收藏」），连同歌词和伴奏存在电脑上，没网也能唱。
- **PK 对战**：两支麦克风唱同一首歌，电视上两条实时分数条，唱完判输赢。
- **合唱模式**：电视上的歌词按谁唱上色，一人蓝色、一人粉色、一起唱金色；按歌词里的「男/女/合」标记分，没有标记就一段一段轮流。
- **手机荧光棒**：手机全屏亮起，颜色跟着电视的氛围灯一起变。
- **包厢系统**：配合管理终端 YTKTV Desk 使用，见上面。
- **其他**：升降调（±6 个半音）、变速、播放队列拖动排序、自动更新。

## 常见问题

**免费吗？可以拿来开 KTV 或酒吧吗？**
都可以。YTKTV 免费，[许可证](LICENSE)允许商用，比如开 KTV；不允许的是出售这个软件本身或它的修改版。另外，在公开场所放音乐通常需要向版权方取得许可，这和软件许可证是两回事。

**需要联网吗？**
需要，歌曲来自 YouTube。队列里接下来的几首会提前下载，所以网络短暂断一下一般听不出来。

**我的声音从音箱出来有延迟，怎么回事？**
几乎都是因为用了无线音箱。AirPlay 本身会延迟 1–2 秒，蓝牙会延迟几百毫秒，这是它们的工作方式，任何设置都改不了。用线把音箱或电视接上（HDMI、USB 或耳机口），然后在 **Mixer → MAIN OUT** 里选它。

**没有显卡能用伴奏吗？**
能。Apple 芯片的 Mac 用自带 GPU；Windows 和 Linux 没有合适的显卡就用 CPU，慢一些，但能用。

**手机打开麦克风页面时提示证书不安全？**
浏览器只允许在加密（HTTPS）页面上使用麦克风，而家庭网络里没法拿到手机信任的证书，所以 YTKTV 自己生成了一个。页面只在你的局域网里，选择继续访问一次即可。

**遇到问题？**
请[提交一个 issue](https://github.com/TonyD365/YTKTV/issues/new/choose)，写上版本、系统和发生了什么。中文英文都可以。
